# EVE-NG Lab Builder

สร้าง lab (Cisco IOL) บน EVE-NG Community จากฟอร์มหน้าเว็บหรือไฟล์ `topology.json` ใช้ Python Standard Library ล้วน

## รัน

1. ใส่รหัสผ่านของ user `evebuilder` (user เฉพาะของเครื่องมือนี้ ล็อกไว้ในโค้ด) ใน `.env` (คัดลอกจาก `.env.example`): `EVE_PASSWORD=...`
2. เปิด terminal ใน VS Code (หรือ PowerShell / Terminal บน macOS) ในโฟลเดอร์นี้:

   ```powershell
   python web_app.py
   ```
3. เปิดเบราว์เซอร์ที่ http://127.0.0.1:8765/ (เปลี่ยนพอร์ตด้วย `--port 9000`) หลีกเลี่ยงพอร์ต 8080 และ 8081: บนเครื่องที่มี proxy/ซอฟต์แวร์ความปลอดภัยขององค์กร พอร์ตเหล่านี้อาจต่อไม่ได้แม้โปรแกรมจะรันอยู่ (ขึ้น ERR_CONNECTION_REFUSED)

ถ้าลืมปิดตัวเก่าแล้วรันซ้ำ โปรแกรมจะปิด EVE Builder ตัวเก่าที่ค้างอยู่ที่พอร์ตเดียวกันให้เอง (รอให้งานที่กำลังทำอยู่เสร็จก่อน) แต่จะไม่ปิดโปรแกรมอื่นที่ใช้พอร์ตนั้น ถ้าตัวเก่าเป็นเวอร์ชันก่อนมีฟีเจอร์นี้ ต้องปิดหน้าต่างเดิมเองครั้งเดียว

ใช้งานแบบไม่เปิดเว็บ: `python eve_builder.py topology.json --recreate --start`

## ปิด

กด `Ctrl+C` ใน terminal ที่รันอยู่ (หรือปิดแท็บ terminal นั้น)

## หน้าต่างๆ ในเว็บ (เมนูด้านบน)

| หน้า | ใช้ทำอะไร |
|------|-----------|
| **เริ่มต้น** | ทางลัดจากโจทย์เป็น lab: 1) คัดลอก prompt ให้ AI พร้อมรูปโจทย์ 2) วาง JSON ที่ AI ตอบ (หรือเลือกไฟล์ `.json` / `.txt`) 3) กด "นำเข้า" ระบบจะแปลงเป็นฟอร์มแล้วพาไปหน้าออกแบบ |
| **ออกแบบ** | แก้ชื่อ lab, อุปกรณ์ (Router/Switch หรือ PC), การเชื่อมต่อ และข้อความ มีผังทางขวาอัปเดตทันที และตรวจความถูกต้องให้อัตโนมัติ (ขึ้นว่า "พร้อมสร้าง" หรือบอกปัญหา) |
| **สร้าง lab** | สร้างใหม่ / เพิ่มลง lab เดิม / ตรวจสอบ / เปิด-ปิดอุปกรณ์ แต่ละปุ่มมีคำอธิบายสั้นๆ และแสดงผลลัพธ์ด้านล่าง |
| **Lab ที่มีอยู่** | ดึงรายการ lab และโฟลเดอร์จาก EVE-NG (จัดเป็นโฟลเดอร์ ค้นหาได้) โหลด lab เข้าฟอร์ม (ดับเบิลคลิกที่ชื่อก็ได้) **ลบ lab** **สร้างโฟลเดอร์** และ **ลบทั้งโฟลเดอร์** |
| **เชื่อมต่อ** | ตั้ง host / HTTPS แล้วทดสอบการเชื่อมต่อ (username ล็อกเป็น `evebuilder` — Community มี user ได้ 2 คน: `admin` ไว้เปิด EVE GUI, `evebuilder` ไว้ให้เครื่องมือนี้ ไม่ชน session กัน; เปลี่ยนที่ `EVE_USERNAME` ใน `eve_builder.py`) |

ปุ่มไอคอนมุมขวาบนเปิด "บันทึกการทำงาน" (ประวัติผลลัพธ์และข้อความจากระบบ) ส่วนจุดสีข้างข้อความ "เชื่อมต่อแล้ว" บอกสถานะการเชื่อมต่อ เมนู **EVE-NG ↗** ท้ายแถบเมนูเปิดหน้าเว็บของ EVE-NG ในแท็บใหม่ โดยใช้ host และ HTTPS ที่ตั้งไว้ในหน้าเชื่อมต่อ ถัดจากเมนูนี้แสดง CPU / MEM ของเครื่อง EVE-NG (รีเฟรชทุก 30 วินาที เฉพาะตอนแท็บเปิดอยู่ และข้ามรอบถ้ากำลัง build/sync อยู่; เป็นสีแดงเมื่อ ≥ 85%) ระบบใช้ user `evebuilder` แยกจาก `admin` ของหน้า EVE GUI จึงไม่เตะ session ของ GUI หน้าเว็บรองรับโหมดมืดตามการตั้งค่าของเครื่อง

## รายละเอียดการทำงาน

- **ทดสอบการเชื่อมต่อ**: login ทดสอบและดึงรายการ IOL image ที่ติดตั้งบน EVE-NG มาเป็นตัวเลือกในช่อง Image (ถ้าพิมพ์ชื่อ image ที่ไม่มีอยู่ ช่องจะเป็นสีแดงและหน้าออกแบบจะแจ้งเป็นปัญหา)
- **ชนิด node**: Router/Switch (IOL) หรือ PC (VPCS) PC ไม่ต้องใส่ image มีพอร์ตเดียวชื่อ `eth0` (ระบบแก้ชื่อพอร์ตใน link ให้อัตโนมัติ)
- **นำเข้าจาก AI**: ปรับชื่อพอร์ตแบบ Gi0/1 เป็น e0/1, เดา type ถ้า AI ไม่ระบุ, ข้ามอุปกรณ์ที่ไม่รองรับ (server/cloud/firewall) และแจ้งสิ่งที่ปรับในกล่องแจ้งเตือนหน้าออกแบบ (ไม่รองรับไฟล์ Excel) ถ้าในฟอร์มมีข้อมูลที่แก้ไว้ ระบบจะถามก่อนแทนที่
- **Config เริ่มต้นจาก AI**: prompt ให้ AI ใส่ `config` (คำสั่ง CLI) ของแต่ละเครื่อง = `hostname`, `no ip domain-lookup`, IP ของแต่ละ interface + `no shutdown`, `write memory` (ไม่รวม routing/ACL ซึ่งเป็นตัวโจทย์) ส่วน PC ได้ `set pcname`, `ip <ip>/<prefix> <gateway>`, `save` ถ้าโจทย์ไม่บอก IP ของ router ให้เลขท้าย = เลข router (R2 → .2) ค่าที่ AI เลือกเองจะแจ้งในกล่องแจ้งเตือน config ของแต่ละเครื่องจะอยู่ในปุ่ม **Config** ของแถวนั้นในหน้าออกแบบ (แก้หรือพิมพ์เองได้)
- **ใส่ config ให้อัตโนมัติ**: ตอนสร้าง lab (หรือเพิ่มเครื่องใหม่ลง lab เดิม) ระบบจะโหลด config เป็น startup-config ให้ เปิดเครื่องครั้งแรกจะได้ hostname และ IP ทันที ไม่ต้องวางใน console เอง บรรทัดที่ใช้ได้แค่ตอนพิมพ์ใน console (`enable`, `conf t`, `end`, `write memory`, `save`) ระบบตัดออกให้เอง
  - ใช้ได้กับ PC (VPCS) และ image `x86_64_crb_linux*` (ทดสอบกับ EVE-NG 6.2) ส่วน IOL รุ่นเก่า `i86bi-linux-*` EVE-NG ไม่โหลด startup-config ให้ ระบบจึงวาง config เป็นกล่องข้อความในผังให้ copy ไปวางใน console แทน (ช่อง Config จะเตือนเป็นสีส้ม)
  - config ใช้ตอนเปิดเครื่องครั้งแรกเท่านั้น ถ้าเครื่องเคยเปิดแล้วต้อง wipe ใน EVE-NG ก่อน ส่วน "เพิ่มลง lab เดิม" ไม่แก้ config ของเครื่องที่มีอยู่แล้ว
  - โหลด lab ที่มีอยู่เข้าฟอร์ม config ที่ตั้งไว้ใน EVE-NG จะกลับมาอยู่ในช่อง Config ด้วย
- **คัดลอก / เพิ่มหลายเครื่อง**: ปุ่ม ⧉ ในแถวสร้างเครื่องใหม่ชนิดและ image เดียวกัน ชื่อถัดไปอัตโนมัติ (R01 → R02) โดยไม่คัดลอก config เพราะ IP จะซ้ำ ปุ่ม "เพิ่มหลายเครื่อง…" เพิ่มทีละหลายเครื่อง เช่น PC1–PC4 (ข้ามชื่อที่มีอยู่แล้ว)
- **ตำแหน่ง node/ข้อความ**: ไม่ต้องกรอก ระบบจัดให้อัตโนมัติ (node ที่เชื่อมต่อกันมากสุดอยู่บนสุด ที่เหลือเรียงเป็นชั้นลงมา ข้อความเรียงเป็นแถวใต้ผัง) ลากกล่องในผังเพื่อย้ายได้ และปุ่ม "จัดตำแหน่งใหม่" ใช้เริ่มใหม่ กด `Ctrl+Z` (ตอนไม่ได้พิมพ์อยู่ในช่องข้อความ) เพื่อย้อนการลากหรือการจัดตำแหน่งใหม่ทีละขั้น ปุ่ม "บันทึกเป็นรูป" บันทึกผังทั้งหมดเป็น PNG ความละเอียด 2 เท่า (สีตามโหมดสว่าง/มืดที่ใช้อยู่)
- **ซูมผัง**: วางเมาส์บนผังแล้วเลื่อนลูกกลิ้งเพื่อซูมเข้า/ออกรอบตำแหน่งเมาส์ (หน้าเว็บจะไม่เลื่อนตามขณะอยู่บนผัง) ลากพื้นหลังเพื่อเลื่อนดู มีปุ่ม − / + / "พอดี" ที่มุมขวาบนของผัง (ดับเบิลคลิกพื้นหลังก็กลับมาพอดีจอ) ซูมได้ 33%–800% และบนทัชแพดใช้การถ่างนิ้วซูมได้
- **พอร์ตใน link**: เลือกจากรายการ ซึ่งสร้างตามจำนวนกลุ่มพอร์ตของอุปกรณ์ (PC มีแค่ `eth0`) พอร์ตที่สายเส้นอื่นใช้แล้วจะเลือกไม่ได้ ถ้าเปลี่ยนอุปกรณ์ปลายสาย ระบบจะเลือกพอร์ตว่างตัวแรกให้ ส่วนพอร์ตที่ไม่มีจริง (เช่น ลดกลุ่มพอร์ตลง) จะขึ้นสีแดง เปลี่ยนชื่ออุปกรณ์แล้ว link จะตามไปด้วย
- **ลบแล้วย้อนกลับได้**: ลบอุปกรณ์จะลบสายที่ต่ออยู่ไปด้วย และมีปุ่ม "ย้อนกลับ" ในแจ้งเตือนด้านล่าง (ประมาณ 8 วินาที)
- **ผังกับฟอร์มเชื่อมกัน**: คลิกอุปกรณ์ สาย หรือข้อความในผัง จะพาไปที่แถวนั้นในฟอร์ม และชี้เมาส์ที่แถวในฟอร์มจะไฮไลต์ในผัง ถ้ามีหลายสายระหว่างอุปกรณ์คู่เดียวกัน ผังจะวางสายเรียงข้างกัน
- **กู้คืนงาน**: งานในหน้าออกแบบที่ยังไม่ได้สร้างหรือเพิ่มลง EVE-NG จะถูกบันทึกในเบราว์เซอร์อัตโนมัติ ถ้าเผลอรีเฟรชหรือปิดแท็บ เปิดใหม่จะมีแถบให้กด "กู้คืน" หรือ "ทิ้ง" (บันทึกแยกตามพอร์ต ถ้าเปลี่ยน `--port` จะไม่เห็นของเดิม)
- **ส่งออก JSON** (หน้าออกแบบ): ดาวน์โหลดฟอร์มเป็นไฟล์รูปแบบเดียวกับ `topology.json` ใช้กับ `python eve_builder.py <ไฟล์>` ได้ หรือนำเข้าใหม่ในหน้าเริ่มต้น (การนำเข้าไม่เก็บโฟลเดอร์และตำแหน่งที่ลากไว้)
- **แนะนำปุ่มในหน้าสร้าง lab**: เมื่อเปิดหน้านี้ ระบบจะเช็กว่ามี lab ชื่อนี้บน EVE-NG แล้วหรือยัง แล้วไฮไลต์ "สร้างใหม่" หรือ "เพิ่มลง lab เดิม" ให้ รวมทั้งเตือนถ้ายังไม่มีโฟลเดอร์ปลายทาง
- **สร้างใหม่**: สร้าง lab บน EVE-NG (ถ้าชื่อซ้ำ ต้องติ๊กลบของเดิมก่อน และมีหน้าต่างยืนยัน)
- **เพิ่มลง lab เดิม**: เพิ่มเฉพาะ node/link/text ที่ยังไม่มีใน lab ที่มีอยู่แล้ว ไม่ลบและไม่แก้ของเดิม (ตำแหน่งที่ลากไว้ใน EVE-NG ไม่หาย) รายการที่ทำไม่ได้ เช่น พอร์ตถูกใช้แล้วหรือ node ไม่มีพอร์ตนั้น จะถูกข้ามและแจ้งในบันทึก
- **โหลด lab ที่มีอยู่**: ดึง node, link และ text มาแก้ในฟอร์ม (รองรับ IOL, PC (VPCS) และ link แบบ node-to-node เท่านั้น รายการอื่น เช่น cloud/QEMU จะถูกข้ามและแจ้งในกล่องแจ้งเตือน)
- **ตรวจสอบ**: เทียบ node (ชื่อ, image, จำนวนพอร์ต) และ link ที่มีจริงบน EVE-NG กับฟอร์ม
- **ลบ lab / ลบโฟลเดอร์** (หน้า Lab ที่มีอยู่): ลบถาวร กู้คืนไม่ได้ มีตัวกันพลาดดังนี้
  - ไม่ลบถ้ายังมีอุปกรณ์ทำงานอยู่ (EVE-NG ลบ lab ที่รันอยู่ให้โดยไม่เตือน ทำให้ process ค้างบนเซิร์ฟเวอร์ ระบบจึงตรวจเอง) ข้อควรรู้: EVE-NG อาจรายงานว่า node "ทำงานอยู่" ใน lab ที่ไม่ได้เปิด ถ้ามี lab อื่นที่ node หมายเลขเดียวกันกำลังรัน ระบบจะปฏิเสธการลบในกรณีนี้ด้วย ให้ปิดอุปกรณ์ที่รันอยู่ก่อน
  - ลบโฟลเดอร์ที่ไม่ว่าง ต้องพิมพ์ชื่อโฟลเดอร์ยืนยัน และหน้าต่างจะบอกจำนวน lab/โฟลเดอร์ย่อยที่จะหาย (EVE-NG ลบทุกอย่างข้างในรวมโฟลเดอร์ย่อย)
  - ลบโฟลเดอร์หลัก `/` ไม่ได้ และ path ที่มี `..` ถูกปฏิเสธ
- **สร้างโฟลเดอร์**: เลือกโฟลเดอร์แม่และตั้งชื่อ (ตัวอักษรอังกฤษ ตัวเลข ช่องว่าง - _ .)

## โครงไฟล์

- `web_app.py` เซิร์ฟเวอร์ · `eve_builder.py` ตัวเชื่อม EVE-NG API · `topology_import.py` ตัวแปลง JSON จาก AI
- `web/index.html` โครงหน้า · `web/app.css` หน้าตา · `web/app.js` การทำงานของหน้าเว็บ
- `web/fonts/` ฟอนต์ [Anuphan](https://github.com/cadsondemak/Anuphan) (ไลเซนส์ SIL OFL, ดูไฟล์ `OFL-Anuphan.txt`) ฝังไว้ในโปรแกรมจึงใช้ได้แม้ออฟไลน์ ถ้าเครื่องติดตั้งฟอนต์ **Sukhumvit Set** ไว้ หน้าเว็บจะใช้ตัวนั้นก่อนโดยอัตโนมัติ (ไม่ได้แจกฟอนต์นี้มาให้เพราะไม่ใช่ฟอนต์ไลเซนส์เปิด) ถ้าอยากเปลี่ยนฟอนต์ แก้ตัวแปร `--font` ที่ต้นไฟล์ `web/app.css`

## หมายเหตุ

- `.env` เก็บรหัสผ่านเป็นข้อความธรรมดา อย่านำไปแชร์หรือ commit
- เซิร์ฟเวอร์ฟังที่ `127.0.0.1` เท่านั้น
- สคริปต์ไม่ใช้ proxy ของระบบ เพราะ EVE-NG อยู่ในเครือข่ายภายใน
